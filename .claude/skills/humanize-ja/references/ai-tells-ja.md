# AI 臭カタログ（日本語）

AI が書いた日本語に出やすいクセの一覧。見つけたら消すか直す。ただし **直すために事実を足してはいけない**。元文の情報の範囲で言い換える。足せないものは語ごと削るのが正解。

## 定型評価語（抽象語の空回り）

抽象語だけで重みを演出する。何が起きたかを書けないときの逃げ。

- 重要な / 極めて重要 / 計り知れない
- 画期的な / 革新的な / 多面的な / 包括的な / 本質的な
- 注目に値する / 注目を集めている / 今後の展開が注目される
- 浮き彫りにする / 浮き彫りになった
- 重要な示唆を与える / 示唆に富む
- 〜と言えるでしょう / 〜ではないでしょうか / 〜と考えられます

直し方。元文に具体があるならそれを動詞で書く。なければその文ごと削る。捏造しての具体化は禁止。

## 安全クッション（逃げ文句）

情報を一切増やさないのに文字数だけ稼ぐ。原則すべて削除。

- 一般的に / 多くの場合 / 往々にして
- 状況によって異なります / ケースバイケース / 一概には言えませんが
- とはいえ / もちろん例外もありますが
- 必ずしも〜とは限りません

本当に留保が要る箇所だけ、短い注意書き一文に圧縮する。

## 説教くさい前置き

読者を子ども扱いする予告。消して内容を直接書く。

- ここで重要なのは〜という点です
- 〜について理解しておく必要があります
- 注意すべき点として
- まず押さえておきたいのは
- 〜を見ていきましょう / 〜について解説します

## 冒頭のテンプレ

いきなり本文に入る。下記で始まっていたら書き直す。

- 結論から言うと / 本記事では / 以下で解説します
- 近年、〜が急速に進展しており
- 〜が注目を集めています
- 現代社会において / 昨今の

## 結論のテンプレ

- 今後の展開が注目されます / ますます重要になるでしょう
- 〜が期待されます
- 以上のことから〜と考えられます
- 参考になれば幸いです / まずは小さく始めましょう / ぜひお試しください

元文の主張の範囲で言い切るか、内容に即した淡い一文で締める。新しい意見・行動提案を発明しない。

## 接続詞の多用

論理を接続詞で塗る。1 文章に 3 回以上なら半分削り、文の順序で繋ぐ。

- 一方で / しかしながら / とはいえ
- 加えて / さらに / そのうえ / また
- このように / そのため / したがって
- とりわけ / 特に

## 否定並列

- 〜ではない。〜だ。（2 回以上続いたら片方を別構文に）
- 単なる X ではなく Y だ
- X が問題なのではない。Y が問題だ。

直し方。Y を直接言う。「問題は Y だ」。否定の助走を捨てる。

## 意義の付け足し

事実の後に AI が勝手な解釈を継ぐ。元文にない解釈なら一文ごと削る。

- 〜を示しており、今後の成長が期待されます
- 〜を物語っています
- これは〜の表れと言えます

## 追従・媚び

- 素晴らしいご質問ですね / 非常に良い指摘です
- おっしゃる通り / まさにその通りです

## 日本語固有

- することができます → できます（さらに「できる」「変えられる」)
- 主語の過剰明示。同じ主語を毎文置かない。日本語は省ける
- 語尾の均一化。ですます調に体言止め・短い断定を混ぜる
- 〜を行う / 〜を実施する → 動詞一語で（「設定を行う」→「設定する」)
- 〜における / 〜に関して / 〜について の乱用

## 記号・カタカナ

- 過剰なカタカナ（ソリューション・レバレッジ・イノベーティブ・アプローチ）。和語で言えるものは和語に
- 太字+コロンの箇条書き（**速度：** 3 倍）。Markdown ごと禁止。format-rules.md 参照
- 全角ダッシュ `——`、過剰な `「」`『』`（）`、`：`、`／`、`→`。format-rules.md 参照

## リズム

- 三点セットの強制。元が 4 点なら 4 点、1 点なら 1 点
- 全文が同じ長さ・同じ型（断定→理由の連続）。長短を混ぜる
- 段落が毎回キメ台詞で終わる。終わり方を変える
