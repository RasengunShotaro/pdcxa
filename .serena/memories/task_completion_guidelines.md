# PDCXA タスク完了時のガイドライン

## 必須実行コマンド

タスク完了時には以下のコマンドを**必ず実行**して品質を確認する：

### 1. 型チェック
```bash
bun check-types
```
- TypeScriptの型エラーがないことを確認
- フロント・バック両方の型安全性を保証

### 2. リント・フォーマット  
```bash  
bun lint
```
- Biome設定に準拠したコードスタイルを確認
- 自動修正可能な問題は自動適用
- Next.jsのリントルールも含む

### 3. テスト実行
```bash
bun test
```
- 既存機能の回帰テストを実行
- 新規追加したテストが通ることを確認
- テストカバレッジの維持

### 4. ビルド確認
```bash
bun build
```
- 本番ビルドが成功することを確認
- バンドルサイズ・最適化の確認
- 依存関係の整合性チェック

## データベース変更時の追加作業

スキーマ変更を行った場合：

### 1. マイグレーション生成・適用
```bash
cd apps/backend
bun drizzle:generate  # マイグレーション生成
bun drizzle:push      # 適用
```

### 2. 型定義同期
```bash
bun check-types      # 型の整合性確認
```
